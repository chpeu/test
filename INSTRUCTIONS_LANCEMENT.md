## 📋 VÉRIFICATION

### **Si erreur**: "Module not found: ccxt"

**Solution**:
```bash
pip install -r requirements.txt
```

### **Si erreur**: "Address already in use"

**Solution**: 
- Une instance est déjà lancée
- Fermer l'autre instance ou changer le port dans `main.py`
