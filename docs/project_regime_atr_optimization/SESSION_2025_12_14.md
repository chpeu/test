## 📊 ANALYSE ROOT CAUSE: UNKNOWN REGIMES

### Résultats SQL (24h / 7j)

| Période | Total Trades | UNKNOWN | % UNKNOWN |
|---------|--------------|---------|-----------|
| 24h | ~15 | ~2 | ~13% |
| 7j | ~150 | ~25 | ~17% |

### Causes identifiées

1. **Régime non initialisé au démarrage**
   - `MarketRegimeSelector` démarre avec `current_regime = UNKNOWN`
   - Trades ouverts avant le premier `check_regime()` réussi

2. **Données ATR/ADX manquantes**
   - Si `atr_values` vide dans `check_regime()` → reste UNKNOWN
   - Pairs sans données suffisantes (nouvelles, illiquides)

3. **Exceptions silencieuses**
   - `try/except` dans `position_manager.py` qui fallback sur UNKNOWN
   - `regime_selector.get_status().get('current_regime', 'UNKNOWN')`

### Code concerné
- `core/market_regime_selector.py` L196-199 (init UNKNOWN)
- `core/market_regime_selector.py` L779-781 (return si pas d'ATR)
- `core/position_manager.py` L2930-2950 (récupération régime)
- `core/position_manager.py` L3330-3350 (fallback UNKNOWN)

## ✅ DÉCISION: STRATÉGIE BACKFILL

### Principe
> **Backfill seulement si les données sont cohérentes avec le régime calculé.**
> Sinon, exclure le trade du dataset ML.

### Critères de cohérence

Un trade backfillé est **cohérent** si:

```python
def is_backfill_coherent(trade: dict, calculated_regime: str) -> bool:
    """
    Vérifie si un trade avec régime backfillé est cohérent.
    
    Critères:
    1. ATR du trade compatible avec le régime
    2. Paramètres de trading (SL/TP) dans la plage du régime
    3. Session/heure cohérente avec les patterns historiques
    """
    
    # 1. ATR cohérent avec régime
    atr_pct = trade.get('entry_atr_1m', 0)
    regime_atr_ranges = {
        'CALME': (0, 0.20),
        'NORMAL': (0.20, 0.50),
        'VOLATILE': (0.50, float('inf')),
        'CHOPPY': (0, float('inf'))  # ADX based, any ATR
    }
    
    if calculated_regime in regime_atr_ranges:
        min_atr, max_atr = regime_atr_ranges[calculated_regime]
        if not (min_atr <= atr_pct < max_atr):
            return False
    
    # 2. Paramètres SL/TP cohérents
    sl_mult = trade.get('entry_atr_mult_sl', 0)
    tp_mult = trade.get('entry_atr_mult_tp', 0)
    
    # Si params enregistrés ne correspondent pas au régime
    regime_param_ranges = {
        'CALME': {'sl': (0.5, 1.2), 'tp': (1.0, 2.5)},
        'NORMAL': {'sl': (0.8, 1.5), 'tp': (1.5, 3.0)},
        'VOLATILE': {'sl': (1.0, 2.0), 'tp': (2.0, 4.0)},
    }
    
    if calculated_regime in regime_param_ranges:
        ranges = regime_param_ranges[calculated_regime]
        # Tolérance: params peuvent être hors plage si ajustement local
        # On accepte si au moins proche (±50%)
        sl_min, sl_max = ranges['sl']
        if sl_mult > 0 and not (sl_min * 0.5 <= sl_mult <= sl_max * 1.5):
            return False
    
    # 3. MFE/MAE présents pour What-If
    if not trade.get('max_price_reached') or not trade.get('min_price_reached'):
        return False
    
    return True
```

### Layer 1: Hard-Stop Criteria

| Critère | Seuil | Action | Fenêtre |
|---------|-------|--------|---------|
| **Drawdown max** | > 5% session | Rollback immédiat | Session en cours |
| **Losing streak** | ≥ 5 trades consécutifs | Rollback immédiat | - |
| **Profit Factor** | < 0.5 | Rollback immédiat | 20 derniers trades |
| **Win Rate** | < 25% | Rollback immédiat | 30 derniers trades |

### Layer 2: Progressive Rollback

```python
class ProgressiveRollback:
    """
    Rollback progressif avec hystérésis et cooldown.
    """
    
    def __init__(self):
        # Fenêtres d'évaluation
        self.short_window = 20   # trades récents
        self.medium_window = 50  # tendance
        self.long_window = 100   # baseline
        
        # Hystérésis
        self.degrade_threshold = 0.15   # -15% vs baseline → dégrade
        self.improve_threshold = 0.10   # +10% vs baseline → peut améliorer
        
        # Cooldown
        self.min_trades_between_changes = 30
        self.min_hours_between_changes = 24
        
        # État
        self.current_adjustment_level = 0  # -2, -1, 0, +1, +2
        self.last_change_trade_id = None
        self.last_change_timestamp = None
    
    def evaluate(self, metrics: dict) -> dict:
        """
        Évalue si un ajustement est nécessaire.
        
        Returns:
            {
                'action': 'hold' | 'degrade' | 'improve' | 'hard_rollback',
                'reason': str,
                'new_level': int,
                'params_delta': dict
            }
        """
        # Hard-stop check first
        if self._check_hard_stop(metrics):
            return {
                'action': 'hard_rollback',
                'reason': self._hard_stop_reason,
                'new_level': 0,
                'params_delta': self._get_baseline_params()
            }
        
        # Cooldown check
        if not self._cooldown_elapsed():
            return {'action': 'hold', 'reason': 'cooldown'}
        
        # Performance comparison
        short_perf = self._calculate_performance(self.short_window)
        baseline_perf = self._calculate_performance(self.long_window)
        
        delta_pct = (short_perf - baseline_perf) / baseline_perf if baseline_perf else 0
        
        # Hystérésis: degrade only if significantly worse
        if delta_pct < -self.degrade_threshold:
            new_level = max(self.current_adjustment_level - 1, -2)
            return {
                'action': 'degrade',
                'reason': f'Performance -{abs(delta_pct)*100:.1f}% vs baseline',
                'new_level': new_level,
                'params_delta': self._get_params_for_level(new_level)
            }
        
        # Improve only if significantly better AND already degraded
        if delta_pct > self.improve_threshold and self.current_adjustment_level < 0:
            new_level = self.current_adjustment_level + 1
            return {
                'action': 'improve',
                'reason': f'Performance +{delta_pct*100:.1f}% vs baseline',
                'new_level': new_level,
                'params_delta': self._get_params_for_level(new_level)
            }
        
        return {'action': 'hold', 'reason': 'within_tolerance'}
```

### Régime-Aware Rollback

```python
def evaluate_by_regime(self, metrics_by_regime: dict) -> dict:
    """
    Évalue séparément pour chaque régime.
    Permet rollback ciblé (ex: rollback VOLATILE mais garder CALME).
    """
    actions = {}
    
    for regime, metrics in metrics_by_regime.items():
        if metrics['trade_count'] < 20:
            actions[regime] = {'action': 'hold', 'reason': 'insufficient_data'}
            continue
        
        actions[regime] = self.evaluate(metrics)
    
    return actions
```

| Métrique | Poids | Description |

| Max Drawdown | 20% | Pire série de pertes |

| Win Rate | 10% | Taux de succès |
